PUBLICACION FRONTEND
Subir el contenido de esta carpeta a la RAIZ del repositorio ACOPIO-AMS/KAMBAN-ACOPIO. El index.html debe quedar en la raíz, no dentro de otra subcarpeta.

PUBLICACION BACKEND
Abrir el Apps Script que recibe los datos, reemplazar el código por backend/INGRESO_DE_DATOS_KANBAN_V3_0.gs y desplegar una nueva versión del MISMO Web App para mantener la URL.

RECUPERACION DE PENDIENTES
No limpiar almacenamiento ni desinstalar la PWA. Una vez publicado frontend + backend 3.0, usar Administrador > PROBAR Y REINTENTAR SINCRONIZACIÓN y luego SOLICITAR REINTENTO EN TODOS LOS EQUIPOS.
